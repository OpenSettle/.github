# OpenSettle

> **Stripe for stablecoins.** Non-custodial payments and billing
> infrastructure for internet businesses that want to accept USDC/USDT
> without giving up custody.

[Website](https://opensettle.io) ·
[Docs](https://opensettle.io/docs) ·
[API explorer](https://api.opensettle.io/v1/docs) ·
[OpenAPI](https://api.opensettle.io/v1/openapi.json) ·
[`@opensettle/sdk` on npm](https://www.npmjs.com/package/@opensettle/sdk) ·
[Status](https://opensettle.io/status)

## Why OpenSettle

- **Non-custodial by design**: merchants keep wallet control and settlement
  flow.
- **Production payment surface**: checkouts, invoices, subscriptions,
  webhooks, refunds, portal, analytics.
- **Multi-chain stablecoin settlement**: Base, Ethereum, Polygon, Arbitrum
  live with USDC/USDT.
- **Developer-first tooling**: typed SDK, OpenAPI snapshots, Postman
  collection, runnable webhook examples.

## Public repositories

- [`opensettle-sdk-js`](https://github.com/OpenSettle/opensettle-sdk-js) -
  official TypeScript/Node SDK (`@opensettle/sdk`).
- [`opensettle-openapi`](https://github.com/OpenSettle/opensettle-openapi) -
  versioned OpenAPI 3.1 spec snapshots.
- [`opensettle-docs`](https://github.com/OpenSettle/opensettle-docs) -
  documentation source for [opensettle.io/docs](https://opensettle.io/docs).
- [`opensettle-webhook-examples`](https://github.com/OpenSettle/opensettle-webhook-examples) -
  webhook verification examples (Node now, more languages following).
- [`opensettle-postman`](https://github.com/OpenSettle/opensettle-postman) -
  importable Postman collection + environment template.
- [`opensettle-integration-examples`](https://github.com/OpenSettle/opensettle-integration-examples) -
  end-to-end merchant integration examples.
- [`opensettle-status`](https://github.com/OpenSettle/opensettle-status) -
  status and incident/postmortem source.
- [`audits`](https://github.com/OpenSettle/audits) -
  security audit summaries and hardening notes.
